# Python OpenCV Image Editor

A simple image editing application developed in Python using **OpenCV** and **Tkinter**.

The project started as a console-based image editor and is being upgraded into a **GUI-based application** to make image editing easier and more user-friendly.

## Features

* Open / load an image from the computer
* View image information
* Resize an image
* Crop an image
* Reset edits to the original image
* Save the edited image
* Select the save location and file name
* User-friendly graphical interface

## Technologies Used

* Python
* OpenCV
* Tkinter

## Project Goal

The main goal of this project is to learn how image processing works in Python while developing a practical image editing application. The project also focuses on converting a command-line program into a graphical user interface.

## Current Development

The project is currently being upgraded from a **console-based interface to a GUI-based interface**.
